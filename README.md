Shows zone level ranges, diplomacy, raids and instances on World Map for Turtle WoW 1.12.1.

## 🛠️ Features
- Shows zone level ranges, diplomacy, raids and instances on World Map.
- Supports Turtle WoW specific zones, dungeons and raids.
- Togglable fishing level requirement.
- Slash commands `/lr` or `/levelrange` for options.
- Clean integration with `myAddOns`.
